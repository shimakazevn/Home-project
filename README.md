# HOME - Bản dịch tiếng Việt

Bản dịch tiếng Việt cho Visual Novel **HOME** (RJ01556529).

### 🌐 Chơi trực tiếp trên Web
👉 **Link chơi:** https://shimakazevn.github.io/Home-project/

Game tương thích tốt trên cả máy tính lẫn điện thoại (Android, iOS). Bạn có thể thêm trang web vào màn hình chính để chơi toàn màn hình như ứng dụng.

---

### 💻 Hướng dẫn cài Patch cho bản PC (Windows)
1. Tải thư mục `patch/` về máy.
2. Chép đè toàn bộ thư mục `patch/` vào thư mục game gốc của bạn.
3. Nhấp đúp vào `CAI_DAT_PATCH_VIET_HOA.bat` để hoàn tất cài đặt.
4. Mở `HOME.exe` và trải nghiệm.

---

### ⚙️ Tiện ích & Phím tắt
- **Nút bánh răng (Góc trái):** Mở bảng điều khiển nhanh để Lưu nhanh (Q.Save), Nạp nhanh (Q.Load), Xuất/Nhập file save `.sav`, Bật toàn màn hình hoặc tải dữ liệu để chơi Offline không cần mạng.
- **Phím tắt khi đọc truyện:**
  - `Enter` / `Space`: Đọc tiếp thoại
  - `Ctrl`: Giữ để tua nhanh
  - `L`: Mở nhật ký hội thoại (Log)
  - `H` / Click phải: Ẩn khung chữ

---

### 📌 Lưu ý
- Khi chơi trên web, tiến trình game được lưu trực tiếp trên trình duyệt của bạn. Bạn nên dùng tính năng **Xuất tệp (.sav)** trong menu bánh răng để sao lưu hoặc chuyển save sang máy khác khi cần.
- Bản dịch được thực hiện phi thương mại nhằm mục đích chia sẻ trải nghiệm. Nếu yêu thích trò chơi, hãy ủng hộ tác giả gốc trên DLsite!
