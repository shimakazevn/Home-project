# HOME - Bản dịch Tiếng Việt

Bản dịch tiếng Việt hoàn chỉnh cho Visual Novel **HOME** (RJ01556529).

Tương thích hoàn hảo trên Trình duyệt Web (PC, Mobile, Tablet) và Bản cài đặt dành cho Windows PC.

---

### 1. Trải nghiệm trực tuyến (Web Game)

**Link chơi trực tiếp:** https://shimakazevn.github.io/Home-project/

* **Không cần cài đặt:** Mở trình duyệt và chơi ngay lập tức trên máy tính, điện thoại Android, iPhone, iPad.
* **Tốc độ cao & Tiết kiệm dung lượng:** Hệ thống tự động nạp hình ảnh và âm thanh chất lượng cao qua Cloud CDN khi người chơi tương tác.
* **Chế độ Chơi ngoại tuyến (Offline Mode):** Hỗ trợ tải toàn bộ tài nguyên game về bộ nhớ thiết bị (IndexedDB) để chơi mượt mà khi không có kết nối mạng.
* **Bảng điều khiển tiện ích:** Nút cài đặt góc trái tích hợp Lưu nhanh (Q.Save), Nạp nhanh (Q.Load), Xuất/Nhập tệp sao lưu `.sav`, Bật/Tắt Toàn màn hình, Tự đọc và Tua nhanh cốt truyện.

---

### 2. Hướng dẫn cài Patch cho Windows PC

Nếu bạn đã có bản game gốc trên máy tính:

1. Tải toàn bộ thư mục dự án hoặc bản phát hành patch.
2. Chép toàn bộ thư mục `patch/` vào thư mục chứa game gốc của bạn.
3. Nhấp đúp vào tệp `CAI_DAT_PATCH_VIET_HOA.bat` để cài đặt tự động.
4. Mở file `HOME.exe` và thưởng thức bản dịch tiếng Việt.

---

### 3. Phím tắt & Thao tác điều khiển

* **Enter / Space:** Đọc tiếp hội thoại
* **Ctrl (giữ):** Tua nhanh cốt truyện
* **L:** Mở nhật ký hội thoại (Backlog)
* **H / Chuột phải:** Ẩn khung thoại để xem ảnh nền
* **Menu bánh răng (Góc trái):** Mở bảng cài đặt nhanh, lưu/nạp và quản lý dữ liệu

---

### 4. Lưu ý về dữ liệu & Bản quyền

* Khi chơi trên web, tiến trình game được lưu trực tiếp trong bộ nhớ trình duyệt của bạn. Bạn nên sử dụng tính năng **Xuất tệp (.sav)** trong menu cài đặt để sao lưu hoặc chuyển file save sang thiết bị khác khi cần.
* Tác phẩm gốc thuộc quyền sở hữu của nhà phát triển **sorarevo** (Mã tác phẩm: `RJ01556529`).
* Dự án Việt hóa này được thực hiện phi thương mại nhằm mục đích chia sẻ và học tập. Vui lòng ủng hộ tác giả gốc trên DLsite nếu bạn yêu thích tác phẩm!
